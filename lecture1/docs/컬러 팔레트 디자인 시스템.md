## CSS 변수 정의

```css
:root {
  /* Primary Colors */
  --color-primary: #F04E23;        /* 브랜드 오렌지-레드 (로고, 버튼, 포인트) */
  --color-primary-light: #FF7A52;  /* 밝은 오렌지 (호버 강조, 배지) */
  --color-primary-dark: #D03A10;   /* 어두운 오렌지 (호버 상태, 눌림 효과) */

  /* Secondary Colors */
  --color-secondary: #1A1A1A;      /* 딥 챠콜 (헤딩, 강조 텍스트) */
  --color-accent: #2B3A2E;         /* 올리브 다크 그린 (히어로 배경, 다크 섹션) */

  /* Background Colors */
  --color-bg-primary: #FFFFFF;     /* 메인 배경 (본문, 카드) */
  --color-bg-secondary: #F5F5F5;   /* 서브 배경 (섹션 구분, 입력 필드) */

  /* Text Colors */
  --color-text-primary: #1A1A1A;   /* 주요 텍스트 (제목, 헤딩) */
  --color-text-secondary: #555555; /* 일반 본문 텍스트 */
  --color-text-muted: #999999;     /* 보조 텍스트 (캡션, 날짜, 메타정보) */

  /* Interactive Colors */
  --color-button-primary: #F04E23; /* 주요 CTA 버튼 배경 */
  --color-button-hover: #D03A10;   /* 버튼 호버 상태 */
  --color-link: #F04E23;           /* 링크 기본 색상 */
  --color-link-hover: #D03A10;     /* 링크 호버 상태 */

  /* Border & Divider */
  --color-border: #E0E0E0;         /* 일반 테두리 */
  --color-divider: #CCCCCC;        /* 섹션 구분선 */
}
```

## 컬러 사용 가이드

### Primary Color — `#F04E23`
- **사용 목적**: 브랜드 아이덴티티를 나타내는 핵심 색상
- **적용 위치**:
  - 로고, 브랜드 마크
  - 주요 CTA(Call-To-Action) 버튼
  - 강조 숫자, 통계 수치
  - 포인트 아이콘, 불릿 마커
- **주의사항**: 남용 시 시각적 피로감이 생기므로 전체 UI의 10% 이내로 제한

### Secondary Color — `#1A1A1A`
- **사용 목적**: 가독성 높은 텍스트 및 강한 대비 표현
- **적용 위치**:
  - 페이지 제목(H1, H2)
  - 헤더 내비게이션 링크
  - 푸터 텍스트
- **주의사항**: 흰 배경 위에서만 사용, 컬러 배경 위에서는 흰색(`#FFFFFF`)으로 대체

### Accent Color — `#2B3A2E`
- **사용 목적**: 고급스러운 분위기와 깊이감 부여
- **적용 위치**:
  - 히어로 섹션 배경 오버레이
  - 풀스크린 배너, 다크 테마 섹션
  - 텍스트 배경 강조 블록
- **주의사항**: 이 색상 위에는 반드시 흰색(`#FFFFFF`) 텍스트 사용

### Background Colors
| 변수 | Hex | 사용처 |
|------|-----|--------|
| `--color-bg-primary` | `#FFFFFF` | 기본 페이지 배경, 카드, 모달 |
| `--color-bg-secondary` | `#F5F5F5` | 섹션 배경 구분, 입력 필드, 코드 블록 |

### Text Colors
| 변수 | Hex | 사용처 |
|------|-----|--------|
| `--color-text-primary` | `#1A1A1A` | H1~H3 헤딩, 카드 제목 |
| `--color-text-secondary` | `#555555` | 본문 단락, 설명 텍스트 |
| `--color-text-muted` | `#999999` | 날짜, 태그, 캡션, 플레이스홀더 |

### Interactive Colors
| 상태 | Hex | 설명 |
|------|-----|------|
| 기본(Default) | `#F04E23` | 버튼 및 링크 기본 상태 |
| 호버(Hover) | `#D03A10` | 마우스 오버 시 (15% 어두운 톤) |
| 포커스(Focus) | `#FF7A52` | 키보드 접근성, 포커스 링 |
| 비활성(Disabled) | `#CCCCCC` | 비활성화 버튼 및 입력 필드 |

## 반응형 고려사항

### 다크모드 대응

```css
@media (prefers-color-scheme: dark) {
  :root {
    /* 배경 반전 */
    --color-bg-primary: #1A1A1A;
    --color-bg-secondary: #2A2A2A;

    /* 텍스트 반전 */
    --color-text-primary: #F5F5F5;
    --color-text-secondary: #CCCCCC;
    --color-text-muted: #888888;

    /* Primary는 유지 (브랜드 일관성) */
    --color-primary: #F04E23;
    --color-primary-light: #FF7A52;
    --color-primary-dark: #D03A10;

    /* 테두리 색상 조정 */
    --color-border: #3A3A3A;
    --color-divider: #444444;
  }
}
```

### 화면 크기별 색상 전략

| 화면 크기 | 전략 |
|-----------|------|
| **모바일 (xs ~ sm)** | 배경 단순화, 텍스트 대비 강화, 버튼 Primary 색상 강조 |
| **태블릿 (md)** | 기본 팔레트 그대로 유지 |
| **데스크톱 (lg ~ xl)** | 히어로 다크 오버레이(`#2B3A2E`) 활용한 풍부한 비주얼 적용 |

### 접근성 (WCAG 2.1 기준)

| 색상 조합 | 대비 비율 | 등급 |
|-----------|-----------|------|
| `#F04E23` on `#FFFFFF` | 3.7:1 | AA (Large Text) |
| `#1A1A1A` on `#FFFFFF` | 16.1:1 | AAA |
| `#FFFFFF` on `#2B3A2E` | 9.2:1 | AAA |
| `#555555` on `#FFFFFF` | 7.4:1 | AAA |

> **주의**: Primary 오렌지(`#F04E23`)는 소형 본문 텍스트에 단독 사용 시 AA 기준 미달.
> 소형 텍스트에는 `--color-primary-dark: #D03A10` 사용을 권장합니다.
